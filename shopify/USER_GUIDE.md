## 3. THEME CUSTOMIZER

### 3.1 Mengakses Theme Settings

1. Buka **Theme Editor** (Online Store → Themes → Customize)
2. Di panel kiri, scroll ke bawah
3. Klik **Theme settings** (icon gear ⚙️)

### 3.2 Theme Settings Available

#### **Colors**

Customize warna brand:

```
Primary Blue:   #005E75  (Main brand color)
Light Blue:     #9AD7E5  (Secondary/accent)
Deep Blue:      #143F58  (Footer/dark sections)
```

**Cara ubah warna:**
1. Klik **Theme settings** → **Colors**
2. Klik color picker untuk setiap warna
3. Masukkan hex code atau pilih dari color picker
4. Klik **Save** di kanan atas

#### **Typography**

Font yang digunakan:

```
Headings:  Cormorant Garamond (Elegant serif)
Body:      Raleway (Modern sans-serif)
```

**Cara ubah font:**
1. Klik **Theme settings** → **Typography**
2. Pilih **Heading font** atau **Body font**
3. Browse dari Google Fonts library
4. Klik **Save**

#### **Logo & Favicon**

**Upload Logo:**
1. Klik **Theme settings** → **Logo**
2. Klik **Select image**
3. Upload logo file (SVG, PNG recommended)
4. Adjust logo width (default: 120px-200px)
5. Klik **Save**

**Upload Favicon:**
1. Klik **Theme settings** → **Favicon**
2. Klik **Select image**
3. Upload favicon (32x32px or 64x64px PNG)
4. Klik **Save**

### 3.3 Page-Specific Customization

**Homepage:**
- Di Theme Editor, pastikan Anda di **Homepage**
- Select dropdown di top: **Home page**

**About Page:**
- Select dropdown: **Pages** → **About**

**Contact Page:**
- Select dropdown: **Pages** → **Contact**

## 4. MENGELOLA SECTIONS

### 4.1 Apa itu Sections?

Sections adalah building blocks dari halaman Shopify. Setiap section adalah module yang bisa di-customize.

**Flores Island Coffee Sections:**
- Hero Home
- Our Values
- Coffee Origin
- Cultivation Story (Interactive Map)
- Coffee Harvest
- Collection Products
- Specialty Beans
- Blog/News
- Newsletter Signup
- Header & Footer

### 4.2 Cara Edit Section

**Step-by-step:**

1. Buka **Theme Editor**
2. Di preview, klik section yang ingin di-edit
   - ATAU klik nama section di left panel
3. Panel kiri akan show settings untuk section tersebut
4. Edit text, images, atau settings
5. Preview changes di center panel
6. Klik **Save** jika sudah sesuai

### 4.3 Cara Tambah Section Baru

1. Buka **Theme Editor**
2. Klik **Add section** di left panel
3. Browse available sections:
   - Hero Home
   - Our Values
   - Coffee Origin
   - Cultivation Story
   - dll.
4. Klik section yang diinginkan
5. Section akan ditambahkan ke halaman
6. Drag & drop untuk reorder position
7. Klik **Save**

### 4.4 Cara Hapus Section

1. Klik section yang ingin dihapus
2. Scroll ke bawah di left panel
3. Klik **Remove section**
4. Confirm removal
5. Klik **Save**

### 4.5 Cara Reorder Sections

1. Di left panel, hover over section name
2. Icon "6 dots" akan muncul (⋮⋮)
3. Click & drag section ke posisi baru
4. Release mouse
5. Klik **Save**

### 4.6 Edit Section Settings

#### **Hero Home Section**

Settings available:
- **Heading:** Main title text
- **Subheading:** Subtitle text
- **Button text:** CTA button label
- **Button link:** URL destination
- **Background image:** Hero image upload

**Example:**
```
Heading: "Premium Coffee from Flores Island"
Subheading: "Sustainably grown, carefully processed"
Button text: "Shop Now"
Button link: /collections/all
```

#### **Our Values Section**

Settings available:
- **Section heading:** Title
- **Value blocks (4 blocks):**
  - Icon selection
  - Title
  - Description

**Cara edit values:**
1. Klik **Our Values** section
2. Expand **Blocks** di left panel
3. Klik value block (Value 1, 2, 3, atau 4)
4. Edit:
   - **Icon:** Choose from icon library
   - **Title:** e.g., "Quality"
   - **Description:** Short description
5. Klik **Save**

#### **Cultivation Story Section (Interactive Map)**

Settings available:
- **Section title:** Main heading
- **Section subtitle:** Description text
- **Location blocks (3 locations):**
  - Location 1: Maumere (Factory)
  - Location 2: Bajawa Ngada (Farm)
  - Location 3: Manggarai (Farm)

**Cara edit location info:**
1. Klik **Cultivation Story** section
2. Expand **Blocks**
3. Klik location block (Location 1, 2, atau 3)
4. Edit:
   - **Location name:** e.g., "Maumere"
   - **Title:** e.g., "Our Factory"
   - **Description:** Location details
   - **Image:** Upload location photo
5. Klik **Save**

**Catatan:** Coordinates sudah di-set otomatis, tidak perlu diubah.

#### **Collection Products Section**

Settings available:
- **Section heading:** Title
- **Collection:** Select collection to display
- **Products to show:** Number (default: 8)
- **Layout:** Grid columns

**Cara select collection:**
1. Klik **Collection Products** section
2. Klik **Collection** dropdown
3. Select collection (e.g., "All Products", "Retail", "Home Brewing")
4. Set **Products to show:** 8
5. Klik **Save**

#### **Blog/News Section**

Settings available:
- **Section heading:** Title
- **Blog:** Select blog
- **Posts to show:** Number (default: 3)

**Cara customize:**
1. Klik **Blog** section
2. Select blog dari dropdown
3. Set number of posts
4. Klik **Save**

#### **Newsletter Signup Section**

Settings available:
- **Heading:** Section title
- **Subheading:** Description
- **Button text:** Submit button label
- **Success message:** Thank you message

**Recommended settings:**
```
Heading: "Stay Updated"
Subheading: "Get news about new coffee releases and special offers"
Button text: "Subscribe"
Success message: "Thank you for subscribing!"
```

## 5. MENAMBAH & EDIT PRODUK

### 5.1 Cara Menambah Produk Baru

**Step-by-step:**

1. Dari Shopify Admin, klik **Products** di sidebar
2. Klik **Add product**
3. Isi form product:

#### **Basic Information**

**Title:**
```
Example: "Flores Arabica - Retail 250g"
```

**Description:**
```
Example:
"Premium Arabica coffee beans from Flores Island. 
Single origin, wet-processed, medium roast.

Tasting notes: Chocolate, caramel, citrus
Altitude: 1,200-1,600 masl
Process: Wet-hulled"
```

#### **Media (Images)**

1. Klik **Add media**
2. Upload product images:
   - Main product photo (front)
   - Package back
   - Product in use
   - Detail shots
3. Recommended: 4-6 images per product
4. Image specs:
   - Format: JPG or PNG
   - Size: 2048x2048px (square recommended)
   - Max file size: 20MB

#### **Pricing**

```
Price:        $25.00
Compare at:   $30.00  (optional - untuk show discount)
Cost per item: $12.00 (optional - untuk tracking)
```

#### **Inventory**

```
SKU:          FLORES-RET-250G
Barcode:      (if available)
Quantity:     100
```

**Track quantity:** ✅ Centang checkbox

#### **Shipping**

```
Weight:       250 g
```

#### **Variants** (Opsional)

Jika produk punya variasi (e.g., 250g, 500g, 1kg):

1. Scroll ke **Variants**
2. Klik **Add variant**
3. Add options:
   - **Option name:** Size
   - **Option values:** 250g, 500g, 1kg
4. Set price & SKU untuk tiap variant

#### **Organization**

**Product type:**
```
Example: Coffee Beans
```

**Vendor:**
```
Example: Flores Island Coffee
```

**Collections:**
- Select collections (e.g., "Retail", "All Products")
- Click "Browse" to select

**Tags:**
```
Example: arabica, single-origin, flores, retail, medium-roast
```
(Comma separated)

#### **Search Engine Listing**

1. Klik **Edit website SEO**
2. **Page title:** 
   ```
   Flores Arabica Retail 250g | Premium Coffee
   ```
3. **Meta description:**
   ```
   Premium Arabica coffee from Flores Island. Single origin, wet-processed, medium roast. Order now for fresh delivery.
   ```
4. **URL handle:**
   ```
   flores-arabica-retail-250g
   ```

### 5.2 Cara Save & Publish Product

1. Setelah semua diisi, scroll ke atas
2. Klik **Save** (tombol biru kanan atas)
3. Product status:
   - **Active:** Visible di store
   - **Draft:** Hidden, not published

### 5.3 Cara Edit Product Existing

1. Klik **Products** di sidebar
2. Klik product yang ingin di-edit
3. Edit fields yang diperlukan
4. Klik **Save**

### 5.4 Cara Duplicate Product

Useful untuk create similar products:

1. Buka product page
2. Klik **Duplicate** (di dropdown menu kanan atas)
3. Edit informasi product baru
4. Save

## 7. UPLOAD & KELOLA GAMBAR

### 7.1 Akses Files Section

1. Dari Shopify Admin, klik **Content** → **Files**
2. Anda akan melihat semua uploaded images

### 7.2 Cara Upload Images

**Step-by-step:**

1. Klik **Upload files**
2. Select images dari computer:
   - Single file: Click file
   - Multiple files: Hold Ctrl/Cmd + click multiple
3. Klik **Open**
4. Wait for upload to complete

### 7.3 Image Specifications

**Recommended specs:**

| Type | Dimensions | Format | Max Size |
|------|------------|--------|----------|
| Product | 2048x2048px | JPG/PNG | 20MB |
| Hero/Banner | 1920x1080px | JPG/WebP | 5MB |
| Blog Featured | 1200x630px | JPG/PNG | 2MB |
| Logo | 400x400px | SVG/PNG | 1MB |
| Favicon | 64x64px | PNG | 100KB |
| Thumbnails | 600x600px | JPG/PNG | 500KB |

### 7.4 Image Optimization Tips

**Before Upload:**
1. Resize to appropriate dimensions
2. Compress using tools:
   - TinyPNG (https://tinypng.com)
   - ImageOptim (Mac)
   - JPEG-Optimizer
3. Convert to WebP for better compression (optional)
4. Use descriptive filenames: `flores-arabica-retail-250g.jpg`

**Alt Text:**
Always add alt text untuk accessibility & SEO:
```
Good: "Flores Arabica coffee retail package 250g front view"
Bad: "image1.jpg" or empty
```

### 7.5 Cara Gunakan Uploaded Images

#### **In Theme Editor:**
1. Click section yang butuh image
2. Click **Select image**
3. Choose dari:
   - **Recently uploaded**
   - **Library** (all uploaded files)
   - **Upload new**
4. Select image → **Select**

#### **In Product:**
1. Edit product
2. **Media** section → **Add media**
3. Select dari library atau upload new

#### **In Blog Post:**
1. Edit blog post
2. Click image icon di editor toolbar
3. **Insert image** → Browse library
4. Select image → **Insert**

### 7.6 Cara Copy Image URL

Untuk use di custom code:

1. Go to **Content** → **Files**
2. Click image thumbnail
3. **Copy** URL dari preview modal
4. URL format:
   ```
   https://cdn.shopify.com/s/files/1/xxxx/xxxx/files/image.jpg
   ```

## 10. TROUBLESHOOTING

### 10.1 Common Issues

#### **Issue: Images not loading**

**Possible causes:**
- Image too large (> 20MB)
- Unsupported format
- Poor internet connection

**Solutions:**
1. Compress image using TinyPNG
2. Resize to recommended dimensions
3. Convert to JPG or PNG
4. Try uploading again

#### **Issue: Changes not showing on live site**

**Solutions:**
1. Click **Save** in Theme Editor
2. Clear browser cache:
   - Chrome: Ctrl+Shift+Delete (Windows) / Cmd+Shift+Delete (Mac)
   - Select "Cached images and files"
   - Clear data
3. Refresh page (Ctrl+F5 / Cmd+Shift+R)
4. Try incognito/private browsing mode

#### **Issue: Can't find uploaded image**

**Solutions:**
1. Go to Content → Files
2. Use search bar to find by filename
3. Check upload completed successfully
4. Re-upload if necessary

#### **Issue: Section not appearing on page**

**Solutions:**
1. Check if section is enabled (toggle switch)
2. Verify section is in correct template
3. Check visibility settings
4. Save and refresh

#### **Issue: Product not showing in collection**

**Solutions:**
1. Edit product
2. Check **Collections** field
3. Ensure correct collection selected
4. Product status is **Active** (not Draft)
5. Save product
